# 知了｜当前版本功能范围

> 文档定位：本文件只列出当前开发版本需要完成的功能，不替代产品 PRD。
> 产品需求基准：[知了语音辩论产品PRD_MVP.md](./知了语音辩论产品PRD_MVP.md)。
> 规则：本文件记录已经确认的当前版本调整；未在本文件调整的产品规则，以原始 PRD 为准。

## 1. 游客与知乎登录

- 用户无需登录即可浏览大厅、进入房间旁听、查看公屏和辩论日志。
- 游客拥有本设备临时昵称，可发送公屏消息和点赞。
- 创建自定义房间、申请上麦和发言前必须完成知乎 OAuth 登录。
- OAuth 完成后返回登录前的房间和操作位置。
- 登录用户展示知乎昵称和头像，OAuth Secret 与用户 Token 仅由服务端保存和使用。

## 2. 房间大厅与话题

- 大厅展示“知乎热榜话题房”和“自定义话题房”。
- 热榜话题房使用知乎热榜接口返回的标题、原文链接、缩略图和摘要。
- 热榜房按接口返回顺序展示“热榜第 N 位”，不伪造知乎热度值或在线人数。
- 私人房是知乎用户个人发起的公开自定义话题房，当前版本只支持手动填写标题。
- 房间内展示与当前主题相关的知乎背景资料，默认 5 篇；每条资料可以跳转知乎原文。
- 知乎接口不可用时展示预置话题，保证大厅和演示链路可用。

## 3. 创建自定义房间

- 知乎登录用户可以创建自定义房间。
- 标题限制为 1～30 字。
- 当前版本的私人房全部公开展示，不提供邀请制、邀请码或邀请链接。
- 创建成功后自动进入房间。
- 创建者只是房间发起者，不拥有主持、抢麦、踢人或结束房间的特权。

## 4. 六麦位与发言锁

- 每个房间固定设置 6 个平等麦位。
- 有空麦位时直接上麦；麦位已满时进入先进先出的等待队列，并可取消排队。
- 同一房间同一时刻只能有一名用户持有发言锁并发布语音。
- 麦上用户点击“开麦”竞争发言锁，先获得服务端确认者开始发言。
- 单次发言最长 120 秒，最后 10 秒提醒，到时自动闭麦。
- 发言结束后本人进入 60 秒冷却，其他麦上用户可以立即竞争发言锁。
- 主动闭麦、下麦、退出房间、断线或超时都会释放发言锁。
- 房间最后一人离开后进入 60 秒回收宽限期；期间有人重新进入则取消回收，超时仍为空则关闭并移除房间。

## 5. 实时语音与房间同步

- 使用成熟 RTC 服务承载实时语音，当前首选腾讯云 TRTC。
- 使用实时同步通道传输在线状态、麦位、队列、发言锁、公屏、点赞和打赏。
- 只有获得发言锁的用户才能发布麦克风音频。
- 当前发言者、剩余时间、排队和冷却状态必须有清晰的视觉提示。
- 首次发言前申请浏览器麦克风权限，并说明语音会用于转写和 AI 总结。
- 用户重连后以服务端房间快照恢复状态，不沿用客户端过期状态。

## 6. 公屏与点赞

- 房间内支持实时文字公屏。
- 新消息实时展示，并支持加载当前房间的历史消息。
- 游客和知乎登录用户都可以发送公屏消息。
- 用户可以对当前发言者的一次发言点赞，并获得即时视觉反馈。
- 公屏和点赞具有基础限频，避免重复提交和演示时刷屏。

## 7. 等级、知豆与打赏

- 新用户默认拥有 100 知豆；知豆是站内虚拟积分，不可提现或兑换真钱。
- 房间中的用户信息展示等级和称号；等级使用原始 PRD 的 6 级阈值。
- 游客和知乎登录用户均可按 5、10、50 知豆打赏当前发言者，但不能打赏自己。
- 打赏成功后原子扣除打赏者余额并全额转入发言者账户，打赏者立即获得剩余余额。
- 被打赏者每次增加 2 经验；被点赞增加 1 经验，每日最多通过点赞获得 50 经验。
- 打赏结果作为高亮系统消息进入公屏历史；账户余额只对本人可见。

## 8. 刘看山辩论日志

- 房间内提供“辩论日志”入口，由用户手动打开。
- 日志按时间展示发言者、发言时间和发言文字记录。
- 发言结束后，将本次发言音频交给 ASR 服务转写。
- ASR 失败时保留失败状态，并允许发言者重新上传本次发言音频；当前版本不提供手填摘要。
- 用户打开日志时，按当前最新发言记录调用知乎直答 API 生成或刷新总结。
- 总结至少包含讨论概览、主要观点、共识、分歧、待解决问题和发言时间线。
- AI 只能依据本场发言记录总结，不补写参与者没有表达的观点。
- AI 总结失败时仍展示已有 ASR 转写，并允许发言者重新上传转写失败的音频。
- 当前版本只展示辩论日志，不自动发布为知乎回答。

## 9. Web 交付

- 首先完成 PC Web 的大厅、创建房间、房间、OAuth 回调和辩论日志体验。
- PC 版交互定型后进行移动端响应式适配，移动端保留完整核心链路。
- 最终提供评委可以直接打开体验的 HTTPS 地址。
- 优先使用知乎 AI Works 自动构建和部署；若运行时不兼容，再迁移到普通 Node.js 服务器。

## 10. 当前版本完成标准

- 游客可以直接进入首页和房间旁听。
- 用户可以完成知乎 OAuth，并在返回原房间后申请上麦。
- 大厅可以展示知乎热榜内容，并能通过自定义标题创建私人房。
- 房间内可以加载与当前主题相关的知乎背景资料并跳转原文。
- 多人进入同一房间后，6 个麦位、等待队列、公屏和发言状态实时同步。
- 两人同时申请发言时，最终只有一人获得发言锁。
- 120 秒发言限制、60 秒冷却和断线释放锁符合规则。
- 房间中的用户可以完成实时语音收听和发言。
- 麦位展示用户等级；用户可以打赏当前发言者，扣款、到账与剩余余额保持一致。
- 辩论日志可以展示真实发言记录并生成结构化总结。
- ASR、直答或知乎内容接口不可用时，核心演示链路仍有可用的降级结果。
- PC Web 核心链路完整，并可通过公网 HTTPS 地址体验。
